# ET Atlas｜外球与内球电子转移

中文交互式 3D 配位化学教学网页。网站运行时不调用任何外部网络资源。

## 运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址（通常是 `http://localhost:3000`）。

## 生产构建

```bash
npm run build
npm run start
```

## 内容

- 外球 / 内球电子转移的可旋转、缩放 3D 分步机制
- 播放、暂停、重置、速度与标签控制
- 可调 λ 与 ΔG° 的 Marcus 势能抛物线
- 正常区、无势垒点与倒转区说明
- Co/Cr、Ru 同位素自交换、Co 自交换与 Taube 氯桥案例
- 桥联配体图谱、对比表和带解析测验
